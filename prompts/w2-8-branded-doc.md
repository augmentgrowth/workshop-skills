# W2 · Step 8 — Branded Document From One Sentence

**Where:** Claude Code, in your **second-brain folder** (the cobalt-design and cobalt-voice skills must be installed there — they came with the workshop skill pack).
**What you'll have when done:** a client-ready, fully Cobalt-branded one-page Word document — from a single sentence.

You watched the host kick this off at the start of the session and reveal the result an hour later. This is the same prompt — run it yourself, on your own topic.

> **No slash command needed.** This prompt calls two skills at once (cobalt-design for the brand system, cobalt-voice for the writing), so you invoke them by naming them — "Use the X and Y skills…" is the manual invocation. They also activate on their own whenever you ask for Cobalt-branded or client-ready work.

## Steps

1. Paste the prompt box below, swapping the announcement topic for one of your own if you like.
2. When Claude asks (or before you run it): tell it **where to save the document** — a new project folder is a good default.
3. Let it run — it writes, renders, checks its own output against the brand spec, and fixes what it finds. This takes a few minutes; that's the render-and-look loop working.
4. **Open the result in Word** — not Preview or Quick Look. Outside Word the brand font (Aptos) substitutes to a serif and the document looks wrong when it isn't.

## The prompt — copy everything in the box

```text
Use the cobalt-design and cobalt-voice skills to write a one-page Word document announcing the new AI enablement program to partner company leaders — client-ready. Before you start, propose where in my vault to save it — suggest a new project folder — and confirm with me.
```

## Done when

A one-page .docx is open in Word: blue title, black headings with dotted rules, branded footer, and copy that reads like Cobalt — not like AI.

## If it goes sideways

- **Fonts look wrong (serif everywhere):** you're previewing outside Word. Open the .docx in actual Word.
- **Any specifics it invented** (dates, names, contacts) are placeholders for you to correct — the skill flags them; fix them before the document goes to anyone real.
