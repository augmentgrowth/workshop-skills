# My Brand Skills Builder

Build your own company's brand skills — the same kind of voice + design package the workshop's Cobalt skills came from, produced from your own materials: your website, a brand PDF, a document that already sounds like you.

You end up with two installed skills (`<your-company>-voice` and `<your-company>-design`) plus proof you can judge by eye: a styled brand voice guide, a design system spec rendered in your own colors and fonts, and a Brand-In-Action PDF showing voice and design working together.

## Install (one prompt)

This skill ships in the workshop-skills repository. Open a Claude Code session in your **second brain** folder and say:

> From github.com/augmentgrowth/workshop-skills, install my-brand-skills-builder into this folder's skills so it's available whenever I work in my second brain.

Claude will place it at `.claude/skills/my-brand-skills-builder/` inside your second brain.

## Use

Say what you want in plain English — the skill fires on its own:

- "**Build my brand skills** — our site is example.com."
- "**Teach Claude our brand** from this brand guidelines PDF."
- "**Update our brand skills** — we changed our primary blue."

Claude interviews you briefly (what sources you have, where the skills should live), builds everything, checks its own output visually before showing you, runs a validation gate on the voice skill, and tells you exactly where everything landed and how to invoke each new skill.

## What you get

| Output | What it is |
|---|---|
| `<your-company>-voice` skill | Writes anything in your voice, with your rules baked in |
| `<your-company>-design` skill | Applies your colors, fonts, and layout rules to anything visual |
| Brand voice guide (HTML + PDF) | Shareable, human-readable — includes calibration pairs so anyone can judge fit |
| Design system spec (HTML + PDF) | Rendered *in* the tokens it documents — a wrong color is visible on sight |
| Three demos | Brand-In-Action PDF + two live browser mockups, generated by your new skills |

## For agents scanning this package

**What this is:** a Claude Code orchestrator skill that builds a complete brand package (voice skill + design skill + rendered proof artifacts) for the user's own company from real source materials.

**When to invoke:** requests to build, set up, or update the user's company brand skills/voice/design system. The trigger description in `SKILL.md` frontmatter governs. For a voice skill alone, route to `voice-skill-builder` instead.

**How to use it:** read `SKILL.md` first; it routes to `references/` files per step and runs the Python under `scripts/` itself (never ask the user to run commands). Fetch every file listed for this skill in the repository README's manifest, preserving the `references/`, `scripts/`, `templates/`, `assets/`, and `examples/` subfolder structure — references load on demand mid-run and a missing one stops the build silently.

**Install target:** `<second-brain>/.claude/skills/my-brand-skills-builder/` (project-level; its outputs land in a `Brand/<company>/` folder beside the user's work).
